Структура программы:
cities.json - фаил с соответсвием городови их координат
static/style.css - внешний вид сайта
templates/city_weather.html - шаблон для страницы с выводом рекомендаций для одежды
templates/index.html - главная страница сайта с городами доступными для проверки погоды
app.py - основной файл для работы
Функции в app.py
index() - подгружает шаблон для главной страницы
weather() - получает данные из cities.json для выбранного города, подгружает шаблон для страницы с рекомндациями, 
использует
get_weather(city_data) - создает запрос на openweathermap с помощью координат выбранного города
get_clothing_recommendation(temp, humidity) - по данным температуры и влажности из запроса дает рекомндации как одетс
